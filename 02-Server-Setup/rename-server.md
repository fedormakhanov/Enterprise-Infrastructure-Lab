# Server Rename Procedure (SRV-DC01)

## Objective
Rename the Windows Server 2022 host to SRV-DC01 following enterprise naming conventions.

## Steps

1. Open Server Manager
2. Navigate to: Local Server → Computer Name
3. Click "Rename"
4. Set the new name: SRV-DC01
5. Restart the server

## Result
The server now follows standard naming conventions used in corporate environments.
