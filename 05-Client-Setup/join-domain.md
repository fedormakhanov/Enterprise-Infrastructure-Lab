# Domain Join Procedure

## Objective
Join a Windows client machine to the corp.local domain.

## Steps

1. Open System Settings → About
2. Click "Rename this PC (advanced)"
3. Select "Domain"
4. Enter: corp.local
5. Provide credentials:
   - Username: admin1
6. Restart the workstation

## Result
The client is now part of the domain and receives GPOs.
