# Users and Groups

## Standard User (user1)

- First Name: User
- Last Name: One
- Username: user1
- OU: Corp Users
- Groups:
  - Domain Users

## Administrator (admin1)

- First Name: Admin
- Last Name: One
- Username: admin1
- OU: Admins
- Groups:
  - Domain Admins
  - Enterprise Admins (auto)
  - Domain Users

## Purpose

This structure demonstrates proper separation of standard users and privileged accounts.
