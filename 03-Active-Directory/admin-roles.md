# Administrative Roles

## Domain Admins

Members of this group have full control over the domain, including:

- User and group management
- GPO creation and linking
- DNS administration
- Security configuration

## Enterprise Admins

Automatically assigned to domain controllers in a single-forest environment.

## Admin Account

- admin1 is the primary administrative account
- Located in the Admins OU
- Follows best practices for privileged identity management
